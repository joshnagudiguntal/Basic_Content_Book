💻 C Programming Notes

Basic C programming notes for beginners.

1. What is C?

C is a general-purpose programming language. It is widely used for system programming, embedded systems and application development.

2. Basic C Program

#include <stdio.h>

int main() {

    printf("Hello World");

    return 0;
}

3. Variables

Variables are used to store data in a C program. 

int age = 20;
float marks = 95.5;
char grade = 'A';

4. Data Types

  • int – Integer values
  • float – Decimal values
  • double – Large decimal values
  • char – Single character

5. If-Else

If-else statements are used for decision making. 

int age = 20;

if (age >= 18) {
    printf("Eligible");
} else {
    printf("Not Eligible");
}

6. Loops

Loops are used to repeat a block of statements. 

for (int i = 1; i <= 5; i++) {
    printf("%d\n", i);
}

7. Functions

A function is a block of code designed to perform a particular task. 

int add(int a, int b) {
    return a + b;
}

8. Arrays

An array stores multiple values of the same data type. 

int numbers[5] = {10, 20, 30, 40, 50};
