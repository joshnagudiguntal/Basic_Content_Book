🗄️ SQL Notes

Basic SQL notes and commands for beginners.

1. What is SQL?

SQL stands for Structured Query Language. It is used to store, retrieve, update and manage data in relational databases.

2. What is a Database?

A database is an organized collection of data that can be easily accessed and managed.

3. CREATE TABLE

The CREATE TABLE command is used to create a new table. 

CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    age INT
);

4. INSERT

INSERT is used to add records into a table. 

INSERT INTO students
VALUES (1, 'Joshna', 20);

5. SELECT

SELECT is used to retrieve data from a table. 

SELECT * FROM students;

6. UPDATE

UPDATE is used to modify existing records. 

UPDATE students
SET age = 21
WHERE id = 1;

7. DELETE

DELETE is used to remove records from a table. 

DELETE FROM students
WHERE id = 1;

8. Important SQL Commands

  • CREATE – Create database objects
  • INSERT – Add data
  • SELECT – Retrieve data
  • UPDATE – Modify data
  • DELETE – Remove data
  • DROP – Remove database objects
