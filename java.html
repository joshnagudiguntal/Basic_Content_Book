☕ Java Notes

Basic Java programming notes for beginners.

1. What is Java?

Java is a high-level, object-oriented programming language. It is widely used for application development, web development and enterprise software.

2. Basic Java Program

class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

3. Variables

Variables are used to store data in a Java program. 

int age = 20;
String name = "Joshna";

System.out.println(name);
System.out.println(age);

4. Data Types

Common Java data types include:

  • int – Integer numbers
  • float – Decimal numbers
  • double – Large decimal values
  • char – Single character
  • boolean – True or False
  • String – Text

5. If-Else

If-else statements are used to make decisions. 

int age = 20;

if (age >= 18) {
    System.out.println("Eligible");
} else {
    System.out.println("Not Eligible");
}

6. Loops

Loops are used to execute a block of code repeatedly. 

for (int i = 0; i < 5; i++) {
    System.out.println(i);
}

7. Classes and Objects

A class is a blueprint for creating objects. An object is an instance of a class.
