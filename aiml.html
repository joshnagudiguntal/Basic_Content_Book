🤖 AI & ML Notes

Basic Artificial Intelligence and Machine Learning notes.

1. What is Artificial Intelligence?

Artificial Intelligence (AI) is a field of computer science that enables machines to perform tasks that normally require human intelligence.

Examples include speech recognition, image recognition, chatbots and recommendation systems.

2. What is Machine Learning?

Machine Learning (ML) is a branch of AI where computers learn patterns from data and use those patterns to make predictions or decisions.

3. Types of Machine Learning

  • Supervised Learning – Learns from labelled data.
  • Unsupervised Learning – Finds patterns in unlabelled data.
  • Reinforcement Learning – Learns through rewards and penalties.

4. Supervised Learning

In supervised learning, the model is trained using input data along with the correct output.

Examples:

  • Linear Regression
  • Decision Tree
  • Support Vector Machine

5. Unsupervised Learning

In unsupervised learning, the model works with data that does not have labelled outputs.

Example: K-Means Clustering

6. Machine Learning Workflow

     ↓
Clean Data
     ↓
Prepare Data
     ↓
Train Model
     ↓
Test Model
     ↓
Make Predictions

7. Applications of AI & ML

  • Chatbots
  • Self-driving systems
  • Recommendation systems
  • Fraud detection
  • Image recognition
  • Speech recognition
  • Medical data analysis
