🐍 Python Notes

Basic Python programming notes for beginners.

1. What is Python?

Python is a high-level, interpreted programming language. It is easy to learn and widely used in web development, data science, artificial intelligence and machine learning.

2. Variables

A variable is used to store data in a program. 

name = "Joshna"
age = 20

print(name)
print(age)

3. Data Types

Common Python data types include:

  • int – Integer numbers
  • float – Decimal numbers
  • str – Text
  • bool – True or False
  • list – Collection of values

4. If-Else

If-else statements are used to make decisions in a program. 

age = 20

if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")

5. Loops

Loops are used to repeat a block of code. 

for i in range(5):
    print(i)

6. Functions

A function is a reusable block of code that performs a specific task. 

def greet():
    print("Hello")

greet()
